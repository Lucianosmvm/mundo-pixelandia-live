# Mundo Pixelândia LIVE

Abra `index.html` no navegador. A simulação começa numa clareira com uma fogueira e mantém o progresso no navegador usado para a transmissão. Use **Controles → Backup** para guardar ou transferir o mundo em JSON.

No painel **Chat simulado da live**, informe um usuário, como `@nico`, e envie `!morador Nico | lenhador`. Use outro usuário para criar um pedreiro, fazendeiro ou minerador. Cada usuário pode ter um morador e usar `!meu` para localizar seu personagem.

A primeira chegada abre a votação por 60 segundos. Qualquer usuário pode enviar `!votar casa` ou `!votar serraria`. Vale o último voto de cada usuário. A casa ganha em caso de empate ou ausência de votos. No teste, o botão **Encerrar votação** permite apurar antes. Os moradores ainda precisam coletar madeira e construir a obra escolhida.

O painel recebe mensagens simuladas. A integração com o chat do YouTube e com o LivePix ainda precisa ser configurada e implementada.
